외형뿐 아니라 사용 흐름까지 손봤습니다. 핵심만 추렸어요.

🏠 홈 · 추천 피드

매칭 맥락을 카드 위에서 바로

  • 매칭률 배지를 카드에 노출해 "왜 추천됐는지" 직관적으로 전달
  • 온라인/활동중 상태와 팀원 아바타 미리보기로 신뢰감 ↑
  • 추천/목록 전환을 세그먼트 컨트롤로 명확하게 구분
  • 좋아요 버튼을 중앙에 키우고 되돌리기를 항상 노출
👥 친구

자주 보는 사람부터 빠르게

  • 즐겨찾기 친구 가로 스트립으로 핵심 친구 1탭 접근
  • 친구 추가 진입점을 상단 배너로 끌어올려 발견성 개선
  • 각 친구 행에서 채팅·통화를 인라인 액션으로 바로 실행
  • 검색을 항상 보이는 위치로 고정
➕ 팀 만들기

입력 부담을 줄인 폼

  • 필수 항목 표시(*)와 글자 수 카운터로 작성 가이드 제공
  • 대표 사진 업로드를 가장 위 큰 영역으로 배치
  • 태그는 토글 칩으로 선택, 선택 수를 실시간 표기(최대 5)
  • 완료 버튼은 조건 충족 전 비활성으로 오류 사전 차단
💬 채팅

중요한 알림을 놓치지 않게

  • 받은 팀 초대를 리스트 최상단 강조 카드로
  • 전체/개인/팀 필터 세그먼트로 빠른 분류
  • 개인·팀 채팅을 색 태그로 구분, 온라인 표시 추가
  • 안 읽은 메시지 배지와 시간 정렬을 명확하게
🙋 프로필 · 인스타 스타일

SNS처럼 친근한 프로필

  • 핸들 + 가로 통계(사진·관심사·친구)로 인스타식 헤더 구성
  • 그라데이션 스토리 링은 Meety 시그니처 색과 자연스럽게 결합
  • 관심사를 하이라이트 원형으로, 사진은 3열 그리드로 표현
  • 그리드/시간표 탭 전환으로 한 화면에서 모두 탐색
🎨 공통 시스템

일관된 디자인 토큰

  • 1개 시그니처 그라데이션(보라→핑크)으로 브랜드 통일
  • 카드 라운드 20–24px · 부드러운 그림자로 깊이감
  • 글래스 플로팅 탭바 + 중앙 FAB(팀 만들기) 강조
  • Pretendard 타이포 · 4px 그리드 간격 체계

이 파일은 디자인 미리보기용 반응형 HTML 목업입니다. 실제 적용은 Jetpack Compose 화면(FeedScreen · MyTeamScreen · MeetingCreateScreen · ChatListScreen · MyPageScreen)에 반영하면 됩니다.
확정해 주시면 Compose 코드로 옮겨드릴게요.
