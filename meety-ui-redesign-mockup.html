4마이페이지 · 정보 위계
통계로 첫인상을 강화, 분홍 배경 제거하고 화이트로 정돈된 카드 구성

주요 개선 포인트

현재 빌드 코드를 기준으로 가장 임팩트 큰 변경 7가지를 정리했어요.

1

컬러 팔레트 정리

보라/핑크/하늘/초록/빨강 7색 혼용 → 브랜드 인디고 1개 + 뉴트럴 그레이 7단계. 그라데이션은 로고·CTA·AI 배너에만.

2

매칭 점수 가시화

스와이프 카드와 상세 화면에 매칭 % 뱃지 추가. AI 추천 이유와 짝지어 사용자가 결정하기 쉬워졌어요.

3

고정 하단 CTA

상세 화면 액션을 스크롤 영역에서 분리해 항상 보이게 고정. 결정 지점이 명확해지고 탭 거리가 줄어요.

4

Pretendard 한글 위계

기본 폰트 → Pretendard. 24/18/14/12 4단계 위계와 -0.3~-1.2px 자간으로 한글 가독성 대폭 개선.

5

일관된 라운드 · 그림자

14·20·28 3단계로 모서리 통일, 4dp shadow 대신 0~12px 다단계 soft shadow로 깊이감 표현.

6

마이페이지 톤 다운

핑크 배경(#F8F1F8)과 그라데이션 배너 제거. 화이트 베이스에 통계 행으로 첫인상을 데이터로 전환.

7

AI 컨텍스트 인라인화

채팅방의 "장소 추천" 떠다니는 버튼을 메시지 흐름 안 인라인 칩으로. 대화의 일부처럼 자연스럽게.

8

하단 네비게이션 추가

홈·내 팀·채팅·마이 4탭 구조를 모든 메인 화면에 일관되게. 현재 화면처럼 기능별 분산 진입을 정리.
