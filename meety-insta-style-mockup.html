프로필 = 통계 바(게시물·친구·매칭) + 3열 그리드 · 친구 = 발견/팔로우(검색→스토리→추천→친구 추가) · 채팅 = DM(메시지·요청 토글, 대화 리스트) · 팀 만들기 = 새 게시물식 작성 폼(대표 사진→이름·소개·태그→옵션 행).
공통 요소: 흑백 라인 아이콘 · #0095f6 블루 액션 버튼 · 보라-핑크 그라데이션은 스토리 링/아바타/로고에만 포인트로 사용.

홈 피드 후보 — A 피드형: 팀=게시물(❤️좋아요=매칭 신청), 세로 스크롤로 인스타 감성 최대 · B 릴스형: 풀스크린 한 팀씩, 우측 세로 액션 바, 기존 스와이프 몰입감 유지 · C 하이브리드: 상단 '오늘의 추천 팀' 스토리 링 + 하단 피드, 탐색·둘러보기 동시 제공 · D 스와이프+인스타 ★: 좌우 스와이프 매칭은 그대로, 카드·버튼·앱바만 인스타 미니멀 톤으로. ✕/❤️ 원형 버튼, 흰 카드, 보라-핑크는 매칭 버튼·MATCH 배지에만 포인트.

채팅방 내부 — 인스타 DM 대화 화면. 내 말풍선은 보라-핑크 그라데이션, 상대는 회색 둥근 말풍선 · 상단바에 아바타·활동 상태·통화/영상 아이콘 · 하트 반응·읽음 표시 · 인스타식 입력 바(카메라 원형 버튼 + 마이크·사진·이모지 아이콘). 팀 단체방은 보낸 사람 이름·아바타, 그룹 통화 배너, 입장 시스템 메시지까지 포함.
